# Independent Wedding Invitation

Independent Vite + React prototype inspired by the public Wedence invitation-creation flow.

## Run locally

Requirements:
- Node.js 18+

Then from this folder:

```powershell
npm install
npm run dev
```

Open the URL Vite prints, usually http://localhost:5173.

## Build

```powershell
npm run build
npm run preview
```

This project is intentionally independent and contains no Wedence backend or source code.
